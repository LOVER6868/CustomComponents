# Documentation

If you're new to the module, read [Getting started](GETTING_STARTED.md). Otherwise, the [feature list](FEATURES.md) is the quickest way to find a component and its example.

The longer guides cover systems that affect several parts of card authoring: [Level](LEVEL.md), [variables](VARIABLES.md), and [PickFromThree](PICKFROMTHREE.md).

For individual effect fields, targeting rules, native behavior and setup details, go to the [reference index](reference/README.md). It includes abilities, queries, zone effects, healing, swapping, stat comparisons and configuration. Those details no longer sit beside the introductory guides.

The [examples](../examples/README.md) are split by the place where the JSON belongs. Check that before pasting a snippet into a card.
