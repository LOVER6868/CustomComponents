# Granting abilities

Use stock grant/remove descriptors with the registered name. Armor is numeric; Charge and Thrash use inherited counters; RandomKeyword resolves to a concrete keyword. `ModifyOperation` supports Add/Set. Durations are Permanent, EndOfTurn and NextFighter. History is published, and removal/expiry uses matching source and duration.

See the [examples or related guide](../../examples/abilities/README.md) and [feature catalog](../FEATURES.md).
