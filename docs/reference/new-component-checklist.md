# Adding a component

Register its managed identity and public fields. Connect serialization, deep copy and pool return. Reuse shared queue/hook owners and preserve model/physical identity. Publish required history and add a small authoring example. Validate relevant behavior and compilation. Stock-object extensions use explicit sidecar lifecycles instead of changing managed layouts.
