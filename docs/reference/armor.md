# Armor

Armor uses custom grantable ID `19` to adapt the stock numeric Armor component. Grant it through `GrantAbilityEffectDescriptor`; choose Add or Set with `ModifyOperation`. Source and duration identify the modifier group for removal. Presentation uses the stock Armor special-ability icon.

See the [examples or related guide](../../examples/abilities/README.md) and [feature catalog](../FEATURES.md).
