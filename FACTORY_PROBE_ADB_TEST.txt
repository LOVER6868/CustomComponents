Pick3 native CardViewFactory feasibility test (2026-10-21)

This build HARD-DISABLES HOLDER_INSPECT even if pick3_holder_inspect.txt is 1.
The old manual sprite renderer, UI, selection and submission are unchanged.
No new CardView is created by this probe.

PowerShell (run after rebuilding AND installing your APK):

$base = '/sdcard/Android/data/com.ea.gp.pvzheroes/files'
adb shell "echo 1 > $base/pick3_factory_probe.txt"
adb shell "echo 0 > $base/pick3_holder_inspect.txt"
adb shell "echo 0 > $base/pick3_async_art.txt"
adb shell "echo 0 > $base/pick3_async_override.txt"
adb shell "echo 0 > $base/pick3_direct_loader.txt"
adb shell "echo 0 > $base/pick3_resident_art.txt"
adb shell "cat $base/pick3_factory_probe.txt"
adb shell am force-stop com.ea.gp.pvzheroes

Open one PickFromThree popup and inspect:
adb logcat -d -v time -s Sprig:I '*:S' | Select-String 'FACTORY_TEST|NATIVE_AVATAR|HOLDER_INSPECT' | Select-Object -Last 50

mode=1 logs whether CardViewFactory and CreateCardAsync(4) are resolvable
without invoking any managed method or creating a card.
mode=2 (unsafe, only if mode=1 and baseline are stable) runs the existing
match-bound DI factory resolution through BNM::TryInvoke and reports
FACTORY_READY or FACTORY_NOT_BOUND. Mode 2 CAN crash; BNM catches managed
exceptions but not native SIGSEGV. It still DOES NOT create CardView objects.

adb shell "echo 0 > $base/pick3_factory_probe.txt"  # fully off

The repository's own older documentation records a native CreateCardAsync
SIGSEGV at address 0x38, so we deliberately do not repeat it here.

MODE 2 UPDATE (2026-10-21): Mode 2 explicitly bypasses the old
NativeAvatarFactoryProbe configuration switch. A new MODE2_TICK line proves
that the popup update reached the probe; INSTANCE_STEP breadcrumbs identify
which managed lookup crashed if a SIGSEGV occurs. EXPECT PROBE_START and
FACTORY_READY or FACTORY_NOT_BOUND (up to 12 attempts). No card is created.
Mode 2 is riskier than mode 1 and may crash if the binder's managed method
invocation is invalid. If crash, send the latest Sprig log plus crash buffer.
